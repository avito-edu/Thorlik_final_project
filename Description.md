Описание домена
Платформа для продажи товаров, где несколько продавцов могут выставлять товары на продажу, а покупатели могут их искать, добавлять в корзину и совершать покупки. Система управляет полным жизненным циклом заказа: от выбора товара до доставки. Ключевые ограничения: каждый заказ может содержать товары от разных продавцов, требуется гарантия консистентности при управлении инвентарем

Ключевые предположения:
Каждый товар имеет фиксированное количество на складе
Заказ не может быть подтвержден, если товар закончился после добавления в корзину

Значимые use cases
UC1: Покупатель ищет и добавляет товары в корзину
Роль: Покупатель
Предусловие: Пользователь залогинен
Основной поток:
Покупатель выполняет поиск по названию, категории или фильтрам (цена, рейтинг)
Система возвращает отфильтрованный список товаров с ценой и наличием
Покупатель кликает на товар, видит подробное описание, отзывы, фото
Выбирает количество и добавляет в корзину
Корзина обновляется с итоговой суммой

UC2: Покупатель оформляет заказ
Роль: Покупатель
Предусловие: Корзина не пуста
Основной поток:
Покупатель переходит на страницу оформления заказа
Выбирает способ оплаты (карта, электронный кошелёк)
Система проверяет наличие товаров в реальном времени
Система резервирует товары (блокирует их от других покупателей)
Отправляет платеж на обработку
При успехе платежа создаёт заказ, отправляет уведомление покупателю и продавцам
Очищает корзину
Обработка ошибок:
Если товар закончился → откатить резервирование, показать ошибку
Если платёж не прошёл → откатить всё, предложить попробовать снова

UC3: Продавец управляет каталогом и инвентарем
Роль: Продавец
Предусловие: Продавец залогинен
Основной поток:
Продавец добавляет новый товар (название, описание, фото, цена, количество)
Система валидирует данные и сохраняет товар
Продавец может редактировать товар, изменять цену, количество на складе
При продаже товара система автоматически снижает количество
Если товар закончился, статус меняется на "нет в наличии"
Продавец видит аналитику: продажи, доходы, популярные товары

UC4: Администратор управляет заказами
Роль: Администратор
Предусловие: Админ залогинен
Основной поток:
Админ видит список всех заказов с фильтрацией по статусу (новый, оплачен, отправлен, доставлен)
Может просмотреть детали заказа
Может удалять профили
